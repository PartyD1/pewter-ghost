# Origin

Pewter Ghost is a new codebase. Code was copied in rather than forked, so `git
blame` here starts at this repository's first commit. This file names the
sources so anyone can look back.

## From Pewter @ 83e2239

**Copied as is**

- `public/phaserAssets/` → `apps/editor/public/phaserAssets/`: the Brackeys tileset
  (`Tilemap_Platformer_V1.0.png` and its Tiled files), the Kenney particles, the
  background, and the audio (`bgm`, `jump`, `landing`, `collect`, `gameOver`).
  Tile indices are unchanged (`TILE` in `contracts.ts`: 1 block, 4 grass-half,
  5 dirt, 6 grass, 7 question), so v1 saves map directly.
- `public/favicon.png`.

**Ported, rewritten around the level model**

- `src/main.ts` → `apps/editor/src/main.ts` (DOM chrome, Phaser boot, saving,
  toolbar and shortcuts; it now also starts the fill loop).
- `src/phaser/editorScene.ts` → `apps/editor/src/editor/` (`EditorScene.ts`,
  `paint.ts`, `pointer.ts`, `camera.ts`, `render.ts`, `play.ts`). Painting writes
  to `LevelModel` (authorship + command undo) rather than straight to tile
  layers; the renderer is the only writer of Phaser layers (G-02, G-03, G-04).
- `src/phaser/UIScene.ts` and `loadingScene.ts` → `editor/UIScene.ts`,
  `editor/LoadingScene.ts`, and DOM UI in `ui/` (toolbar, palette, dialogs, toasts).
- `src/phaser/ExternalClasses/Slime.ts`, `UltraSlime.ts` → `entities/` with pure,
  time-based `brains.ts` (the old ones counted frames, so they fired 2.4× as often
  at 144 Hz) and patrol spans taken from the model (G-06).
- The old play-mode knight's constants are kept for reference only in
  `player/legacyKnight.ts`. Nothing runs on them.
- Save format: v1 files still load (`level/save.ts` migrates them); new saves are v2.

**Dropped, never copied**

`src/languageModel/` (in-browser model calls, with the key in the bundle),
`src/enemySystem/`, `gameScene.ts`, `regenerator.ts`, `ExternalClasses/RegenerationTools.ts`,
`ExternalClasses/worldFacts.ts`, `selectionBox.ts`, `OverlapChecker.ts`, `chatbox.css`,
`colors.ts` (Z-level colours of the selection boxes),
and `ExternalClasses/Pathfinding.ts` (the easystar grid search; the playtest agent replaces it).
The selection-box gestures and the chat UI went with them.
The old Pages `deploy.yml` passed `VITE_LLM_API_KEY` to the client build, so it was not
reused. CI is `.github/workflows/pewter-ghost.yml`, which instead fails if a key pattern reaches `dist/`.

## From the Player Physics Fork @ b36ff59

**Copied verbatim** (only comment paths changed from `__tests__/x.test.ts` to `./x.test.ts`):

- `src/phaser/playerPhysics.ts`, `playerController.ts`, `jumpSolver.ts`,
  `movementCapabilities.ts` → `apps/editor/src/player/`
- their tests: `playerPhysics.test.ts`, `jumpSolver.test.ts`, `jumpSolverEngine.test.ts`,
  `movementCapabilities.test.ts`, `reachableFrontier.test.ts`, and `phaserInternals.d.ts`.

This gives a frame-rate-independent knight with coyote time and a jump buffer,
used as is in Play mode. The solver's exact reach tables are exported as
`packages/jump-tables` (`tables.json`, regenerated by `npm run jump-tables`). The
window builder, brief, validator, rule check and agent all read their jump numbers from them.
